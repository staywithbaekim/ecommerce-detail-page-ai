## 工作原则

- 一个 Codex 任务对应一个连贯且可验收的成果。
- 长期事实写入仓库，不依赖聊天记录作为唯一依据。
- 技术验证通过前不进入全面开发。
- 用户原始 PSD、素材和人工参考结果只读使用，任何实验都在副本或临时目录中完成。
