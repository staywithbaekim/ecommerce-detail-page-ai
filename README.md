## 工作原则

- 默认先读取短上下文和任务相关文件，不把完整状态日志、全部验证报告或生成目录注入每轮上下文。
- 一个 Codex 任务对应一个连贯且可验收的成果。
- 长期事实写入仓库，不依赖聊天记录作为唯一依据。
- 客户业务口径、页面结构和验收输入确认后再冻结桌面端设计。
- `TPL-01`、`AI-01`、`SIZE-01` 直接作为正式模块纵向实现并在实现中验收，不建设一次性验证 Demo。
- 用户原始 PSD、素材和人工参考结果只读使用，任何实验都在副本或临时目录中完成。
