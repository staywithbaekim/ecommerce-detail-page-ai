# ARCH-01 B-03 AI 分析页面状态迁移验证

## 范围

本轮迁移 WPF AI 分析页面状态和页面协调，不改变页面行为、XAML 结构或 Application 合同。新增 `src/Desktop.App/AiAnalysisPageState.cs`，由它持有 AI 投影、款式/筛选集合、选中款、展开集合、候选预览、替换目标与素材、授权弹层、忙碌状态、状态消息、命令实例和刷新计时器；新增 `src/Desktop.App/AiAnalysisViewModel.cs` 接管命令初始化、Top-N/筛选操作和页面状态协调。`MainWindowViewModel.Ai.cs` 保留兼容转发属性，`MainWindowViewModel` 仍承担导航、跨页面协调、AI 工作流依赖和全局生命周期。

## 迁移核对

- 原有 XAML 绑定名称保持不变：`AiStyles`、`VisibleAiStyles`、`AiStatusFilters`、授权/预览/替换属性及全部 AI 命令仍由 `MainWindowViewModel` 暴露。
- `Results`、`SizeTables`、`ReferenceLearning` 对 AI 工作流、投影和忙碌状态的现有调用保持不变；没有把 Application 服务放入页面状态对象。
- 页面协调对象不持有 `IAiBatchAnalysisWorkflow`；命令处理通过 Shell 兼容入口复用既有跨页面延续路径。
- 投影刷新继续恢复选中款、展开款式、替换目标和已选素材；授权继续支持扫描与参考学习两个延续动作。
- 自动刷新仍按页面可见性、scheduler 控制状态和子页面等待/分析状态启停；私有计时器字段与页面状态同步，以保留既有 UI 诊断的反射入口。
- 未修改主 XAML、AI result schema、RenderPlan、SQLite migration、checkpoint、manifest、颜色规则、真实 AI/Photoshop 调用、源 PSD、源照片或正式输出。
