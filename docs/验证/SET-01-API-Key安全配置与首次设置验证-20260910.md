# SET-01：API Key 安全配置与首次设置验证（2026-09-10）

## 范围与边界

本记录只覆盖设置页的本机 API Key 输入、更换、移除、脱敏显示、状态检查和首次扫描引导。实现不修改 PRD，不调用真实 AI，不打开 Photoshop，不读取、修补或重试旧失败批次，也不改变以下已批准边界：

- 请求体最大 `16 MiB`；单请求最多 `24` 张；ready buffer `32`；HTTP 并发 `8`；WIC 副本准备最多 `2` 路；请求超时 `180` 秒；预算、重试和 `AiResultUnknown` 语义保持不变。
- API Key 只属于当前 Windows 用户的安全凭据存储。完整 Key 不进入 SQLite、manifest、日志、缓存、模板包、诊断包或 UI 状态模型。
- 本轮“重新读取”只检查本机 Credential Manager，不等同于供应商连接测试；真实 API 请求需要独立的联网与费用确认。

## 实现

| 层 | 产物 | 结果 |
| --- | --- | --- |
| Application | `IAiCredentialManagementPort`、`AiCredentialStatusSnapshot`、`AiCredentialRules` | 供应商无关；状态只有 `NotConfigured`、`Configured`、`Unavailable`，只允许脱敏尾号 |
| Infrastructure | `WindowsCredentialSource` | 固定 Generic target `AI-01-VolcArk-Test`，Generic type `1`；支持 `CredWriteW`、`CredDeleteW` 和按需读取；UTF-8 blob 上限 `512` bytes |
| Desktop DI | `DesktopServices` | `IAiCredentialSource` 与 `IAiCredentialManagementPort` 共享同一 Windows 实现实例 |
| WPF 设置页 | `MainWindow.xaml`、`DesignSystem.xaml`、`MainWindowViewModel.Credentials.cs` | 复用 SectionCard、FieldPasswordBox、Primary/Secondary/Danger 按钮；输入、更换、移除、重新读取、尾号和本地状态文案均有 AutomationId |
| 首次分析 | `MainWindowViewModel.Ai.cs` | 生产组合读取不到已配置 Key 时切换到“设置 → AI 服务”并在 HTTP 前阻断；保存动作不自动调用 AI |

Key 输入在 `PasswordBox` 中只保留到保存完成或窗口释放；成功保存后 ViewModel 和 PasswordBox 清空。状态接口从不返回完整 Key。
