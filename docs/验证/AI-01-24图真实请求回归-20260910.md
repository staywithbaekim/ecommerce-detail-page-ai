### 离线修正

根据火山方舟 Responses API 官方响应结构（`status`、`incomplete_details`、`output[].content[].type=output_text`、`usage`）完成以下有界修正：

- 在状态分支前解析 provider usage；即使结果失败或不完整，也把已观察 usage 交给 scheduler 记账。截断 `output_text` 不做 Markdown 去围栏、宽松 JSON 或部分恢复。
