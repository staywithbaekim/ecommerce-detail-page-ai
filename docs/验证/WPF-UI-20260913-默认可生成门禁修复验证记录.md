# TPL-LEARN-01 默认可生成门禁修复验证记录

日期：2026-09-13

## 目的

修复目标批次分析完成后的交互：AI 已经为图片框填入可用 Top-1 候选时，候选应直接进入生成队列；用户不需要逐框点击确认。用户只有在认为当前用图不合适时，才通过“替换用图”选择并保存另一张照片。没有安全候选的红色页面仍然隔离，不能为了让按钮变绿而误放行。

## 实现范围

- `AiPageAnalysisProjection.CanGenerate` 将绿色和不需要人工配置的黄色页面视为可生成。
- `AiBatchAnalysisProjection` 的可生成页数、进度文本、生成门禁和 RenderPlan 准备均使用同一页面级门禁；黄色页不会再被统计为 `0/N`。
- 仅在真正缺少必需匹配、变体冲突、无安全候选、活动主体分析或显式人工选图模式时保留人工阻断。
- 款式筛选中的“可生成”包含已填好的黄色页面；“待检查”不再把可直接生成的黄色页重复列为待确认。
- 已收口批次的 `ReviewRequired` 不再继续显示可暂停/取消的运行态控制。
- “改用这张并保存”仍是用户主动替换入口；默认 AI 选图不会调用 `LockSelectionAsync`，替换后才写入人工锁定。
