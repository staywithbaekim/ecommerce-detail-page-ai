## 根因计算

V3 在相同网络上的上传速率约为 `7,056,022 / 121.074 ≈ 0.47 Mbps`。旧 V2 请求体按
该速率仅上传预计约 225 秒，超过 180 秒硬截止。V3 比 V2 减少约 46.2%，但 17:49
这次成功请求与 17:09 失败请求是不同 request id，账单不能互相替代。

## 已落实的修复

- 新请求默认使用 `wic-bounded/max1280/jpeg-q76/png-opaque-jpeg/v3`，只生成应用内部
  分析副本；源照片、PSD 和正式输出哈希不变。
- 适配器按上传/响应阶段区分提交失败与结果未知：未上传完成的超时/网络中断返回
  `RetryableError`；上传完成后无响应仍为 `AiResultUnknown`，禁止自动重发。
- scheduler 仅对提交阶段错误使用既有安全重试上限；WPF 显示“AI 请求未送达 / 火山
  未受理 / 重试分析”。
