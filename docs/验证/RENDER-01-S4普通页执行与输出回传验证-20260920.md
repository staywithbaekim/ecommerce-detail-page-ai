## 范围与已有实现

沿用正式 owner、session、broker、资源租约及 UXP main，增加普通页 Photoshop 执行和受认证输出字节回传。不是替代 bridge 或旧验证插件；生产 availability 守卫保留。外部依赖为当前 Photoshop/UDT 和已登记的只读 G03 模板、商品照片；不安装、不使用浏览器，不操作源文件。

- ADR-014 增加可选绝对 placement、能力声明及显式迁移器；新计划身份和 digest 必须更新。旧计划可读不等于可执行。生产 builder/冻结修订兼容及动态尺码 `targets=[]` 尚未闭合。
- Application 提交前核对精确模板 hash/长度、画布、结构签名、目标及旧替换栈；已由多次真实运行的 PLAN_ACCEPTED 验证。worker 嵌入对象 kind 为 `data`，零基路径转换为正式一基路径。
- UXP 执行器只打开已下载验证的新模板 lease，按记录的文档身份执行，校验目标及固定结构，按计划绝对几何替换和放置，保存新的 PSD/JPG 副本并关闭受控文档。长 modal 有独立认证心跳，取消在安全边界处理。
- 输出采用原会话的 `output_write/output_seal/output_receipt`，128 KiB 分块、2 GiB 总上限、身份/MAC/偏移/hash 校验、CreateNew、flush 和整文件 hash。receipt 只确认暂存字节；不代表媒体校验、原子发布或 SQLite checkpoint。正式 reservation 拒绝由插件直接报告 execution_completed。
