## 本轮代码范围与边界

- `AdapterWorkLoop` 接通领取、ACK、资源 staging、重复领取保护和准备前/后取消；尚无 Photoshop 执行器。丢 ACK、坏资源或宿主阻断清会话并释放确切副本，不盲目重执行。
- `BridgeSessionOwner` 增加实际提交、查询、取消及输出 reservation 接管；输出 reservation 仅允许 never，不代表实际输出传输、提交或 checkpoint。
- JS 摘要按原始 JSON 数字文本重算，保留 .NET decimal/G29 与 Unicode 转义一致性；两组跨语言向量覆盖超 JS 精度数字。
- 新增提交前模板结构证据校验：把计划模板 hash/长度、画布、结构签名、目标和替换栈对回现有 PSD inspection。依据真实 worker，嵌入智能对象 kind 为 `data`；拒绝外部链接、隐藏父层、错 ID/路径、重叠目标。该新增校验晚于上面的资源实机 run，不能把旧 run 当作新校验已实机通过。
- 已确认并修正新手工校准绑定的零基路径问题：worker/UI 路径保持零基，生成领域绑定时逐段 +1；safe_bounds 保留画布绝对位置并与画布取交集。已有冻结修订不原地迁移；旧错误绑定必须在执行前被结构证据门拒绝，兼容迁移/重新校准仍需显式收口。
