# ARCH-01 B-16 分析页面职责抽取验证

日期：2026-09-18。范围：ADR-031 阶段 2 的 AI 页面工作流归属，不改变分析、授权、选图和渲染合同。

## 结果

- `AiAnalysisViewModel` 直接拥有 `IAiBatchAnalysisWorkflow`，负责开始/恢复/控制/刷新、授权读写与弹层续接、候选预览/人工替换/尺码图选择、投影重建、筛选及自动刷新计时器。它不再持有或订阅 `MainWindowViewModel`。
- `IAiAnalysisHost` 提供跨页批次上下文、导航、凭据检查、结果投影应用及参考学习交接。重试仍由批次协调器建立新草稿并扫描，保留原代数隔离与状态文案，不重排旧请求图。
- 结果入口的 RenderPlan 准备调用、尺码保存后的计划准备、旧批次的 AI 恢复、参考学习前上传授权也经 AI 协调器执行；Shell 不再持有 AI 工作流字段。
- Shell 保留原公开属性/命令、私有诊断入口、`_aiPageState` 和 `_aiRefreshTimer` 镜像。导航/窗口宽度变化显式通知页面；页面自身通知向 Shell 单向转发。兼容删除仍等待真实退出证据。
- 款式/页面/候选条目迁到 `AiAnalysisItemViewModels.cs`。款式展开状态直接归属 AI 协调器；接受旧 Shell 参数的两个构造入口保留并委托新协调器，避免提前破坏兼容。
- `tmp/arch-b16-baseline` 保存抽取前工作树。33 个 AI 方法经 host 名称归一化后 token 序列一致；初始化、投影重绑定、授权续接和渲染交接另经差异及行为回归核对。
