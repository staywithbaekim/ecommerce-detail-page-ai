# ARCH-01 B-18 模板与参考学习职责抽取验证

## 职责与兼容边界

`TemplateWorkspaceViewModel` 直接拥有模板库、导入、草稿写锁、校准、页面选择加载版本、模板对话框和参考学习命令。模板手动校准与参考学习共享同一草稿、页面选择和画布，因此由同一协调器的两个 partial 管理；未在两种模式之间增加转发接口。六个模板/学习端口及目录选择器迁出 Shell，协调器通过 `ITemplateWorkspaceHost` 只取得导航可见性和上传授权。

`TemplateWorkspacePageViewModel` 持有协调器，原页面绑定转向协调器/状态；Shell 保留兼容属性、命令、跨页转发、通知和生命周期。条目模型迁入两个独立文件，四种 RelayCommand 实现原样移到公共命令文件。原私有模板/学习编排已移走；不保留第二套业务实现。

在 B-18 原始验证时，公开 Shell 入口、`ShellPageViewModel` 适配层、`_currentBatchId` 和 `_aiRefreshTimer` 诊断镜像继续保留。模板内部私有字段随实际所有者迁移，15 个既有测试/夹具成员的反射目标改为协调器，原行为断言保留。后续收口补充已删除两个镜像，动态适配也已移除；普通 Shell 通知基类仍保留。
