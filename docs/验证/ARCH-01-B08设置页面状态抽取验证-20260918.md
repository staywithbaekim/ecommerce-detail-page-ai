# ARCH-01 B-08 设置页面状态抽取验证（2026-09-18）

## 范围

B-08 将设置页的凭据展示状态从 `MainWindowViewModel.Credentials.cs` 移入 `SettingsPageState`，由 `SettingsPageViewModel` 持有并转发。抽取覆盖：

- 凭据状态、脱敏尾号和用户文案；
- 输入缓冲、忙碌状态和保存/刷新/移除按钮可用性；
- 设置页所需的状态变更通知。

Windows 凭据管理端口、保存/删除副作用、AI 请求前的凭据门禁和 PasswordBox 清理事件仍由 Shell/Application 入口负责。本轮不把安全存储或 provider 逻辑放入页面。

## 实施结果

- 新增 `src/Desktop.App/SettingsPageState.cs`，不持有 `IAiCredentialManagementPort`、provider、SQLite 或批次上下文。
- `SettingsPageViewModel.State` 成为凭据展示状态的页面持有者；页面通知由页面 ViewModel 转发。
- `MainWindowViewModel.Credentials.cs` 只保留凭据端口调用、命令和跨页门禁，删除原本地状态字段。
- 保存、读取、移除、失败提示、忙碌态、输入清理和“保存不会调用 AI”的语义保持不变。
- AI 结果合同、RenderPlan、SQLite/checkpoint、颜色规划、源媒体只读和正式输出原子性均未改变。
