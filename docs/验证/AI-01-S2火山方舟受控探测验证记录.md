1. 当前 Key、测试项目、Responses 端点、候选模型和图片 URL 在本环境可用；新西兰网络不是“完全无法调用”的充分解释。

## 本轮合同修正（2026-08-30）

- `IAiAnalysisCopyPreparer`/`FileAiAnalysisCopyPreparer` 从 INPUT-01 的 `BatchDraft.Assets` 只读源登记创建应用自有副本；副本独立计算 `sha256:` digest，记录字节长度、可信 MIME、尺寸、压缩配置版本和 lease，生产前后复核源 hash 不变。源路径、源字节、Key 和原始响应不进入合同或持久化。
- `FileAiAnalysisCopySource` 在 `OpenAsync` 时读取并校验副本 sidecar 与实际字节；`VolcArkAiAdapter` 只使用已复核 MIME/digest，不再删除带 lease 的副本，避免 429/5xx 重试和第一层→第二层分析复用失效。legacy 无 lease double 仅保留离线兼容清理。
- `IAiAnalysisResultStore`/`FileAiAnalysisResultStore` 以 `results/{request_id}.json` 原子保存并校验 `ai-analysis-result/v1`；scheduler 先保存结果再推进 ledger/session/cache，缺失或损坏结果不能形成 Validated/cache 命中。
- adapter 请求体在构造前按副本 metadata 预估上限；响应 Content-Length 预检、chunked 受限读取并复用 linked timeout token。`RealProbeThroughFormalAdapter` 现为默认跳过、仅设置 `AI01_RUN_REAL_PROBE=1` 且提供批准临时副本时执行的正式探测入口；未启用不计为真实证据。

以上是离线合同与安全边界证据，不新增真实 API 请求；历史一次真实结构化探测仍是唯一真实调用，不能据此冻结 S2 生产参数或宣称 AI-01 完成。

副本 profile 当前明确为 `byte-preserving/provisional-v1`：它验证只读输入、应用自有副本、digest/MIME/尺寸闭合和生命周期，不代表已经执行图片重编码，也不冻结最长边、质量或成本参数。lease token 集合写入应用自有 sidecar，可由新进程恢复；调度器在重试、暂停、第一层转精细分析和共享引用期间保留租约，只有终结/取消且无其他活动引用时才释放。源文件在准备期间变化会使本次应用副本与 metadata 回滚，源文件本身不由应用写回。
