# ARCH-01 B-07 结果页面状态抽取验证（2026-09-18）

## 范围

B-07 将结果检查页的纯展示状态从 `MainWindowViewModel.Results.cs` 移入 `ResultReviewPageState`，并让 `ResultReviewPageViewModel` 持有该状态。抽取覆盖：

- RenderPlan 准备事实及结果状态文案；
- 页面/款式卡片集合、筛选集合和筛选后的投影；
- 当前页面选择、上一页/下一页边界和窄版布局断点；
- 结果页筛选、页面分组和页面详情所需的通知。

RenderPlan 生成、AI 工作流调用、批次导航、尺码表保存、SQLite/checkpoint、正式输出和源媒体访问仍由既有 Shell/Application 入口负责。本轮只改变展示状态归属。

## 实施结果

- 新增 `src/Desktop.App/ResultReviewPageState.cs`，不持有 scheduler、provider、持久化端口或可变批次上下文。
- `ResultReviewPageViewModel.State` 成为结果页面集合、筛选、选择和布局状态的唯一页面持有者；页面通知由页面 ViewModel 转发。
- `MainWindowViewModel.Results.cs` 只保留导航、异步 RenderPlan 准备委托和兼容公开别名，不再持有结果集合、筛选器或布局字段。
- 页面 ViewModel 在工作流初始化前构造，避免结果状态晚于页面绑定创建；既有命令顺序和跨页入口保持不变。
- 颜色版本、同色素材选择、RenderPlan schema、SQLite migration/checkpoint、源媒体只读和正式输出原子性均未改变。
