- 可见框复核关注剪贴窗口优先、贡献证据拒绝、旧绑定兼容、输出 `safe_bounds` 与实际 placement 一致；弹窗复核关注页面归属、异步版本、取消语义、焦点及未确认选择回滚；数据库复核关注连接所有权在配置成功后才移交。这些路径在本轮检查中未发现新的可复现代码阻断，仍不能替代上面的实际环境门。
- 构建目标依赖 `tools/build-psd-inspection-worker.ps1` 和 `tools/project-python.ps1`，后者沿用既有仓库固定环境，不引入系统 Python 回退或安装依赖。普通 build 在缺少该环境时会明确失败；当前本机冷构建不是全新开发机、Release publish 或客户机安装证明。
- `.codex/config.toml` 未跟踪并由共享规则排除。四份包含客户样本细节的旧报告原来仅在 `.git/info/exclude` 中排除，现在也按精确路径加入共享 `.gitignore`，文件留在原处；不忽略整个验证目录，以免吞掉共享结论。
- 候选路径检查排除了 PSD/PSB、照片、数据库、exe/dll、日志/TRX、`tmp`、`bin/obj`、缓存、`node_modules`、`dist`、`graphify-out` 和机器配置。v4/v5/v6 Schema 是合同源码，不能当生成物删掉。新增行扫描未发现私钥、常见 provider token 或长字面量凭据；这是有限模式检查，不声称万能秘密检测。
- 修正短交接中被后续验收覆盖的旧语态，保留原历史事实；本轮生产源文件与测试内容没有修改。详细清单、补丁、TRX、冷构建和本机指纹只在忽略目录保存，真实 Git 索引不变。
