## 2026-09-09 真实 24 图请求体超限诊断（历史发现）

### 事实证据

- 本次真实失败批次为 `batch-42ee2db23d2144549aa82bbb031bf581`；输入 manifest 与 journal 均显示为 `Committed`。
- 该批次包含 1 个款式、24 张素材，源文件合计 `115,669,269` 字节（约 115.7 MB），其中 9 张为 PNG、15 张为 JPEG。
- 6 个模板页面共用一个款式级 `ProductJointUnderstanding` 联合分析请求，并不是 6 个彼此独立的请求；该请求失败会使 6 个页面同时显示失败。
- 当前 `VolcArkAiAdapter` 的 `MaxRequestBytes` 为 `16 * 1024 * 1024`，限制对象是序列化后的 HTTP JSON 请求体，不是单张图片，也不是源目录总大小。
- 当前 `WicAnalysisImageCodec` 在使用正式 `wic-bounded/max1600/jpeg-q82/png/v1` profile 时，输出格式仍跟随输入格式；PNG 经过缩放后仍为 PNG。图片写入 JSON 前还要经过 Base64 编码，离线按当前 profile 重算该批次联合请求约为 `51–53 MiB`，超过 16 MiB。
- 超限在本地 adapter 的 HTTP 前安全门返回 `AI_PROVIDER_REQUEST_TOO_LARGE`，未进入 `HttpClient.SendAsync`；本轮没有为验证该问题重新调用真实 AI。

### 为什么既有 24 张自动化门没有发现

既有 `RequestAtApprovedAssetLimitIsAcceptedAndCanReachProvider` 只验证素材数量门、调度入队和 mock provider 调用，使用的是小尺寸测试素材/模拟副本；它没有用真实批次的 WIC 编码结果构造完整 Base64 JSON 请求体。因此“24 张数量合规”与“真实请求体不超过 16 MiB”是两个不同的验收事实，前者通过不代表后者通过。

### 修正边界

- 不提高 16 MiB、24 张、ready buffer 32、HTTP 并发 8、WIC 准备最多 2 路等已批准安全边界。
- 在应用自有分析副本层增加经过版本化的有界编码策略：无透明通道的照片型 PNG 可转为受控 JPEG；保留真实透明语义的素材不得被错误抹除。编码完成后必须以实际序列化请求体再次测量，超限必须在 provider 前给出明确原因。
- 将 `AI_PROVIDER_REQUEST_TOO_LARGE` 投影为用户可见的具体错误与处理动作，不能继续只显示笼统的“分析失败”。
- 增加真实 24 图夹具的“编码副本大小—Base64—最终 JSON—provider=0/放行”回归；修复前不把本轮性能自动化子门或 `PERF-01` 写成完整通过。
- 如果经过受控编码仍有真实请求无法放入 16 MiB，应另行评审保持整组语义的有界拆分合同；不得直接删除安全门或无证据放大上限。

该诊断不修改用户 PSD、源照片、模板规则或正式输出；旧失败批次不修补、不复用。

## 2026-09-09 真实请求体编码修正与离线回归（本轮完成）

### 实现

- 应用自有副本默认切换到版本化 `wic-bounded/max1600/jpeg-q82/png-opaque-jpeg/v2`：最长边 1600、JPEG q82、源文件 64 MiB、副本 8 MiB、100M 像素。
- V2 对无实际透明度的 PNG 输出 JPEG；检测到非 255 alpha 的 PNG 保留 PNG，避免破坏透明语义。V1/V1-candidate 旧副本仍可读，V2 使用 `analysis-copy-v2-*` 引用与 fingerprint 隔离。
- `VolcArkAiAdapter` 先构造最终 `JsonObject`，使用 `Encoding.UTF8.GetBytes(root.ToJsonString(...))` 获得实际 HTTP body；该字节数是唯一 16 MiB 预检口径。超限在 `HttpClient.SendAsync` 前返回不可重试的 `AI_PROVIDER_REQUEST_TOO_LARGE`，不会发送 AI 请求。
- scheduler 将该错误写入可恢复的 requestId→errorCode 终态 map；WPF 投影明确显示“请求体过大，需要重新建立批次”、实际 JSON 超过 16 MiB、未发送 AI 请求及“重新建立批次”动作。16 MiB、24 张、ready 32、HTTP 8、WIC 2 路、180 秒和预算/未知结果边界均未改变。
