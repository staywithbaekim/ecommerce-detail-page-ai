# WPF UI：替换按钮文案与批次进度实时刷新修复

**日期：** 2026-09-13
**范围：** `Desktop.App` 批次 AI 分析页与“款式检查”页
**本轮没有调用真实 AI，也没有修改源 PSD、源照片或正式输出。**

## 用户可见问题

1. 替换操作的最终按钮文案是“保存并改用这张”，动作顺序不符合用户理解。
2. 进度显示曾停留在 `2/6`、`3/6` 等旧快照。进入“款式检查”后自动刷新会停止；另外，一个款式只要有页面先进入“待人工复核”，整体状态就可能不再是“分析中”，剩余页面仍在分析却不会继续轮询。

## 根因

- `ShouldAutoRefreshAi` 只判断 `IsAiAnalysisVisible`，进入 `AiStyleReview` 后定时器被停掉。
- 只看 `AiBatchUiStatus.Waiting/Analysing` 不够。聚合状态可能已经是 `ReviewRequired`，但某些页面仍为 `Waiting` 或 `Analysing`。
- `MetaText` 和 `AiBatchProgressText` 都来自最近一次 `AiBatchAnalysisProjection`；没有新的投影就会继续显示旧计数，并非页面自身重新计算失败。

## 修复

- 最终按钮统一为“改用这张并保存”，说明文字同步使用该顺序；提交前仍不改变当前用图，只有选中新照片并点击按钮才写入本地锁定记录。
- 自动刷新同时允许“生成前检查”和“款式检查”两个页面。
- 自动刷新以运行中的调度器和所有页面状态为准：只要任一页面仍是 `Waiting`/`Analysing`，就每秒读取一次最新本地状态；全部页面收口、暂停、等待网络或离开批次页后停止。
- 进度文本增加 WPF `LiveSetting=Polite`，投影变化时总览和筛选行同步更新。
