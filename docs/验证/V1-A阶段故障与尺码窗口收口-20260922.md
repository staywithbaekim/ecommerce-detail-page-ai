## 本轮发现与修复验证

1. UXP 执行异常后的 `close(pulse)` 在关闭受控文档之前仍请求认证心跳；会话丢失会使清理提前失败。现改为本地 modal 清理，保留严格文档 ID/名称/活动文档/唯一文档检查，不改变 Unknown 或自动重投边界。新增持续断线回归在修复前确实失败，修复后插件全套 226/226 通过、开发包重建/Reload 和以上新实机复验通过。
2. `RenderPageCommitter.WriteNew` 在写入、flush 或原子发布失败时可能留下自建 `.pending` 元数据。修复复用 Windows 文件身份，只清理确切临时文件，并保留原始 I/O 异常。包含新目标占用负例的 `BridgeExecutionBrokerTests` 115/115 通过；新实机复验第一页提交也经过修复。目标占用故障不替代真实磁盘满验收。
3. 尺码弹层的内层固定 1080×680，而旧窗口测试仅检查遮罩边界。现改为可用空间内布局、三栏按比例分配、操作按钮按组换行，补打开焦点、Escape 关闭/焦点归还及 UIA 名称。加强后的内容/三个面板/六个按钮边界和不重叠断言，在初版比例布局的 1100×760 条件确实报出“行操作按钮与列操作按钮重叠”；改为 WrapPanel 后，与合法符号/空格门禁、Shell 焦点/UIA/中文文本三项聚焦测试一起 3/3 通过。宽/窄尺寸测试使用 1440×900、1100×760，不代替125%实机证据。

本轮完整 solution 构建 0 警告/0 错误；窄窗二次修复后受影响 UI 项目及依赖构建同为 0/0；probe 构建0/0。UXP 开发包已重建与实机 Reload，未创建 `.ccx`。未重复执行全仓库测试矩阵。
