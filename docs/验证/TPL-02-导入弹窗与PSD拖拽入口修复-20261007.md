# TPL-02：导入弹窗与 PSD 拖拽入口修复

日期：2026-10-07（Asia/Shanghai）。对应 TPL02-UI01/UI03/UI06/S01 的局部 UI 门；不关闭 TPL-02，不改变 PSD 解析、规则、AI、RenderPlan/Bridge 或正式输出合同。

## 用户反馈与改动

- 原三个按钮含义不清，尤其“包含已选文件夹的子目录”不符合普通用户语言。现改为：
  - **选择 PSD 文件**：选择一个或多个 .psd 文件；
  - **选择模板文件夹**：扫描所选文件夹直属的 PSD，不自动深入子目录；
  - **扫描子文件夹**：扫描已经选择的文件夹及其所有子目录，追加发现的 PSD，不清空当前清单。
- 原“导入清单中的 PSD”改为 **添加到模板工作台**；“加入路径”改为“添加路径”，并保留粘贴路径能力。
- 弹窗改用当前工作台的浅色、圆角、主次按钮、说明文字、列表和拖拽投放区域，不再出现旧式裸窗口控件组合。
- PSD 文件或文件夹可直接拖入弹窗；拖入文件自动加入清单，拖入文件夹默认扫描直属 PSD；工作台空态和当前工作区也接受 PSD/文件夹拖拽。
- 原文件仍只读，导入链路仍由现有 ImportPsdFilesAsync 复制到应用所有目录后再解析；没有修改源 PSD。
