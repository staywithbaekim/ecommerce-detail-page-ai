## 失败与修复

- 先前 run `45f1826dfd3440ac96a3d95788f96f50` 认证后存储失败，错误为 `BRIDGE_PAIRING_STORAGE_UNAVAILABLE`，自然超时 exit1。UDT 只读 API 类型检查确认 secureStorage 无 getKeys，有 length/key/getItem/setItem/removeItem；改成有界 length/key 枚举后新码配对成功。这不是网络权限错误。
- 重连探针 session 87217 在 UDT 尚未成功重载时超时 exit1，输出 `DEVICE_RECONNECT_FAILED`。重新观察、实际重载后，session 5210 验证通过，未并行启动两个 listener。
- 此前 listener 回归先后 80/81、79/81、79/81。脱敏 bind 错误指向 AccessDenied，端口 57209 位于 Windows 排除段 57191–57290。改为对 127.0.0.1:0 一次 bind，由 OS 选临时端口，随后检查 49152–65535；没有扫描/重试端口、没有修改系统范围或防火墙。该修改后前轮 listener/device/journal/DI 81/81。
- 本轮追加 Windows 保存后常量时间读回、受保护旧值备份读回及失败回滚；UXP 也校验受保护备份后才替换当前值。设置页 DataContext 更换会取消旧配对。两端保存不是分布式原子事务；Windows 失败时 UI 明示可能尚未同步，需重新配对，不自动尝试旧秘密、不开放执行。
