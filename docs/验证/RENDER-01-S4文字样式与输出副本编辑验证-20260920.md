## 独立文字样式检查

原 `TextSha256` 仅证明字符串不变。现有 PSD worker 增加 `text_style_sha256`，覆盖完整 EngineData、字体资源、样式/段落 runs、transform、warp、版本和文字 descriptor。未知字段或缺少必要 engine 数据按不可验证处理；正式输出验证要求模板和输出的每个文字层均有有效摘要且相等。旧 worker 结果可读，但不能据其关闭文字输出门。

PS 26.8.1 保存实测会补齐 `TxMg=TxNM`，并刷新 descriptor 的计算型 bounds；仅规范化前者的缺省值和排除后者，实际图层像素/bounds 仍由现有验证器分别检查。字体、字号、段落、transform、warp、文字、混合值变化和未知字段均有拒绝测试。

## 原生 Photoshop 实际编辑

环境：Photoshop `26.8.1 (20250624.r.8 5e0d05d)`、UXP `uxp-8.3.0-uxp-b1d8c85`。从上述正式 PSD 复制至独立目录 `tmp/render01-editability-20260920-59a8e9a378424b78b6a8e4f9e2236643/`，只编辑 `render01-editability-controlled-copy.psd`。

1. 原生 UI 打开副本，选中 `front_main`，属性确认嵌入智能对象，执行“编辑内容”。
2. 对副本嵌入内容执行反相、保存，返回父 PSD 后看到修改已写回。
3. 以文字工具选中现有文字层，将文字改为“编辑验证副本”，应用并保存父 PSD。
4. 项目 Python 只读打开保存后的 PSD：原文字层 ID37 内容改变且仍为 type；智能对象 ID247 嵌入数据 hash 改变且仍为 embedded data。37 个图层身份/类型和 14 个文字层保留，其余 13 个文字层的内容及样式证据完全一致。
5. 确认副本无未保存标记后关闭该副本，未关闭 Photoshop 或用户文档。
