# ARCH-01 B-15 批次输入职责抽取验证

日期：2026-09-18。范围：ADR-031 原阶段 2 的批次输入工作流、命令与生命周期抽取。

## 结果

- 新增独立 `BatchInputViewModel`，由批次页面拥有，直接依赖已有目录选择器、批次输入工作流与模板读取服务。它拥有 13 个命令、模板页加载、目录选择、扫描取消源、草稿写锁、草稿代数、恢复应用及输入状态通知。
- `IBatchInputHost` 仅提供跨页导航、模板库刷新、授权检查和 AI 开始/恢复交接；Shell 保留这些跨页协调、布局、公开兼容别名及 `_currentBatchId` 诊断镜像，不再持有 `IBatchInputWorkflow`、扫描取消源或草稿写锁。
- `BatchInputPageState` 保持纯展示状态。原批次提交/投影/接口/行类型逐字移至 `BatchInputContracts.cs`；公共名称和命名空间未变，不改变持久化或 Application/AI/RenderPlan 合同。
- 旧实现保留在 `tmp/arch-b15-baseline`。11 个原工作流方法经 host 调用名称归一化后 token 序列一致，涵盖模板加载、目录选择、扫描、重试、草稿代数、写锁和错误映射。恢复的 AI handoff、导航及通知迁移另经差异和 WPF 回归检查。
- 页面原有状态设置入口保留；未借此修改选图模式/PSD 选项的保存语义。模板和参考学习仍使用 Shell 中共享的目录选择器，待各自编排迁移时收敛。
