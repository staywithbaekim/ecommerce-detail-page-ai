# ARCH-01 页面边界与兼容退出门验证（2026-09-18）

## 范围

本记录覆盖 B-05 页面绑定边界收敛及 B-06 模板工作区调用边界迁移。B-05 先让 AI 分析页、批次输入页、结果检查页和设置页改用各自页面 ViewModel 的显式属性；B-06 再把模板画布、拖放、标定和参考学习事件迁移到模板页面 ViewModel。Shell 兼容适配仍保留在过渡 ViewModel 内部，等待外部退出门证据。

本轮没有改变 AI 结果、RenderPlan、SQLite/checkpoint、manifest、bridge、颜色规则或正式输出行为，也没有调用真实 AI provider 或 Photoshop。

## 实施结果

- `AiAnalysisViewModel` 现在实现 `INotifyPropertyChanged` 和 `IDisposable`，向 AI 页面暴露状态、集合、布局值和命令；AI 页面以及候选预览、上传授权弹层不再使用 `Shell.*` 绑定。
- `BatchInputPageViewModel` 暴露批次配置、扫描状态、页面选择集合和批次命令；批次页面 code-behind 通过页面对象调用 PSD 导入和目录选择。
- `ResultReviewPageViewModel` 暴露结果筛选、结果分组、单页详情和页面导航命令；结果页的相对命令绑定指向 `ResultReviewPage`。
- `SettingsPageViewModel` 暴露凭据和上传授权状态、命令及安全输入入口；设置页密码框不再直接访问 Shell。
- 过渡基类的 `ICustomTypeDescriptor` 现在优先返回页面对象自己的显式属性，再补齐 Shell 的尚未迁移属性；因此已迁移页面实际按页面合同解析绑定，不只是增加未被 WPF 使用的转发成员。
- `TemplateWorkspacePageViewModel` 仍保留 `Shell` 作为临时画布/参考学习事件桥。该桥的退出条件是调用方搜索、真实验收、自动化重启和旧 SQLite/结果读取证据齐全；删除必须单独变更。

## B-06 模板工作区页面边界收敛（2026-09-18）

- `TemplateWorkspacePage.xaml.cs` 已改为只通过 `TemplateWorkspacePageViewModel` 访问页面状态和操作，不再通过 `MainWindowViewModel` 取值或执行命令。
- 模板工作区的画布平移/缩放、PSD 导入和拖放、标定素材绑定、标定拖动/键盘、参考学习模式判断、页面排序和滚轮交互均保留原有入口，只更换了调用边界。

- 模板卡片和模板详情 `DataTemplate` 已从 `MainWindow.Resources` 移入 `TemplateWorkspacePage.Resources`，命令祖先改为 `TemplateWorkspacePage`；主窗口不再为模板页面提供 `AncestorType=Window` 的命令绑定资源。

- 模板校准的 Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z 和 Delete 快捷键已从 `MainWindow` 迁入 `TemplateWorkspacePage` 的预览键盘事件；主窗口不再判断模板校准状态。

- 批次页面选择、尺码表编辑、模板确认和重复 PSD 复核四个弹层已分别挂到批次、结果和模板页面；`MainWindow.xaml` 不再实例化这些页面级弹层。

- `TemplateWorkspacePageViewModel` 继续作为过渡适配层，把尚未完成真实退出门验证的模板/参考学习状态转发到 Shell。该层没有改变持久化合同、源媒体安全边界、RenderPlan 或产品规则。
