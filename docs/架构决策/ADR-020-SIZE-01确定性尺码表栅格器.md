# ADR-020：SIZE-01 确定性尺码表栅格器

## 状态

已实施为 SIZE-01 候选，待 SIZE-S7 治理复核和产品视觉走查。该决策只选择渲染机制，不降低 PRD 1.5、ADR-014 或任务书的真实金标、源文件安全、动态行列和视觉验收要求。

## 日期

2026-09-01

## 背景

动态尺码页不能直接贴市场尺码图，也不能使用生成式图片。AI-01 已提供来源可追溯的结构化候选，RenderPlan v1 已冻结 `deterministic_size_table` 逻辑资源，但此前没有把可变行列数据转换为无损资源的正式实现。基础设施项目已经使用 WindowsDesktop/WPF/WIC，桌面 V1 只支持受控 Windows 环境，因此 SIZE-01 需要在不引入第二套图像依赖和不泄漏 Photoshop 命令的前提下关闭这条边界。

## 决策

1. 领域层保存品类中立的 `SizeTable`、来源 hash、原文单元格、状态、revision 和稳定数据摘要；`/`、`\`、`-` 是合法非空原文，真正空字符串才是缺值。业务校验和来源选择不进入栅格器。
2. Application 层定义参数化的 `SizeTableRasterStyle` 与 `ISizeTableRasterizer`。样式版本绑定批次冻结的模板规则摘要，布局版本为显式 ID；栅格器只接受 `Valid` 表格。
3. Infrastructure 使用 WPF `DrawingVisual`、`FormattedText`、`RenderTargetBitmap` 和 `PngBitmapEncoder` 在独立 STA 线程生成 PNG。DPI 固定为 96、`pixelsPerDip` 固定为 1，不读取 WPF 当前窗口 DPI，也不调用 Photoshop、AI 或网络。
4. V1 字体为 `Microsoft YaHei UI`。资源身份同时包含领域数据摘要、全部样式参数、栅格器版本、固定 DPI 和解析到的字体版本签名；字体不可解析时 fail closed。由此避免字体升级后以同一资源 ID 覆盖旧内容。
5. 布局按表头和逐格原文测量自然列宽，再在模板绑定的目标宽度内均分剩余空间；行高取固定最小值与真实文字高度的较大值，表格高度随行数变化。内容超过宽度/高度边界时阻断，不截断、不缩小到不可读，也不猜值。
6. PNG 写入应用拥有的内容寻址路径，先由原子文件存储校验后提交。失败不会覆盖旧资源、旧计划或正式输出；源市场尺码图、源 PSD 和源照片始终只读。
7. RenderPlan 只登记资源 ID、`deterministic_size_table` 用途、MIME、hash、长度、结构化行列和摘要，不登记内部相对路径、字体文件路径或 WPF 类型。Photoshop/UXP 仍只消费 renderer-neutral `render-plan/v1`。

## 候选与取舍

| 方案 | 优点 | 风险 | 结论 |
| --- | --- | --- | --- |
| WPF 固定 96 DPI 参数化栅格 | 复用已批准 Windows 运行时；中文度量、无损 PNG 和应用内预览可共用；不增加包 | 字体版本会影响字形 | 采用；字体签名进入资源身份并在 S7 记录环境 |
| 直接贴市场尺码图 | 实现简单 | 不能保持模板样式和结构化编辑，违反 PRD/ADR-014 | 不采用 |
| 生成式图片 | 可快速得到外观 | 会虚构内容且不可确定复现 | 禁止 |
| 在 UXP/JSX 中排表 | 靠近 Photoshop | 把业务/布局规则泄漏到执行适配器，破坏 RenderPlan 中立边界 | 不采用 |

## 后果

- 相同结构、模板规则、样式参数、字体签名和栅格器版本产生相同资源 ID；PNG 内容 hash 是实际字节的最终证据。
- 运行环境字体发生变化会形成新的资源 ID，不会覆盖旧资源；发布验收仍需记录 Windows、.NET、字体版本和重复渲染 hash。
- 模板固定标题、说明和装饰仍由 PSD 内部副本负责；本栅格器只生成结构化表格资源。正式智能对象位置和 Photoshop 原子输出继续属于 RENDER-01。
- 若后续跨平台或需完全内嵌字体，必须新增批准的字体资产合同和 ADR，不能在当前实现中静默替换字体或引入未授权字体文件。

## 验证门

- `/`、`\`、`-` 三种整列原文、4/6/8 行和不同列数的重复生成 hash；
- 空单元格、低置信、来源冲突、损坏状态、超宽/超高和字体不可用的 fail-closed；
- 同一表重复 PNG 字节/hash、字体签名、96 DPI、内容寻址路径和失败无覆盖；
- `render-plan/v1` Schema、资源引用闭合、普通页/动态页互斥、计划摘要和当前页 revision 隔离；
- 100%/125% DPI、1100×760、UIA、键盘与中文输入的 O-03 实机走查。
