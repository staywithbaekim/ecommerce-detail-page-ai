# ADR-010：模板组增量页面与批次快照

## 状态

已批准，作为 V1 模板维护和任务可恢复性的长期数据边界。

## 日期

2026-08-25

## 背景

用户需要在已经校准并长期使用的模板组中继续添加新页面。例如，一个原有五页的模板组增加第六个 PSD 页面时，用户只应设置和校准新增页，不应重做原五页。与此同时，模板更新不能改变已经创建、正在分析、等待生成、生成中或已完成批次的页面集合和规则，否则任务恢复和历史结果将失去确定性。

## 决策

1. 模板组在产品中仍表现为一个可直接更新的当前模板，不向用户暴露永久历史版本列表。
2. 内部每次成功更新产生不可变的模板修订标识。新增页面具有稳定页面标识，并与其 PSD 副本、页面属性、图片框绑定和校准规则一起写入新修订。
3. “添加页面”只创建和校准新增页。原页面的稳定标识、PSD 副本和校准规则直接继承；只有用户主动修改且结构发生变化的原页面进入重新绑定。
4. 更新采用原子提交。新增 PSD 复制、校验、页面配置和校准结果全部有效后才切换模板组当前修订；失败时继续使用更新前修订，并清理未提交副本。
5. 批次创建时记录所选模板修订、页面标识、页面顺序和规则快照。模板组后续更新不得改变已经创建批次的分析、生成、恢复或历史结果。
6. 尚未分析的草稿可以由用户明确更新到模板组最新修订；更新时重新展示页面选择并要求确认。分析开始后不得切换模板修订。
7. 模板包只导出当前有效修订及其完整页面和规则，不导出历史批次快照、任务历史或内部废弃修订。

## 影响

- 模板存储需要区分用户可见模板组标识、内部模板修订标识和稳定页面标识。
- 任务模型和 `RenderPlan` 生成入口必须读取批次快照，而不是运行时追随模板组当前状态。
- 缓存键中的规则版本应包含模板修订或等价规则摘要，避免新增页后误用旧规则结果。
- 后续实现和验收必须覆盖五页模板新增第六页、原五页规则保持、失败回滚以及旧批次恢复不变。
