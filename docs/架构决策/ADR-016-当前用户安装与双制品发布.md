# ADR-016：当前用户安装与双制品发布

## 状态

已批准并冻结 V1 交付边界；签名能力、正式 UXP `.ccx`、客户机安装/升级/回滚和卸载行为仍由 `INSTALL-01` 技术验证。

## 日期

2026-08-27

## 背景

V1 先以项目方协助安装的封闭小范围内测交付，不进入应用商店、不公开下载、不做后台自动更新。桌面应用和 Photoshop UXP 插件必须配套，但不能要求客户自行判断版本，也不能分发 Photoshop 本体或客户数据。

## 决策

1. 使用当前 Windows 用户范围的签名 bootstrapper；WPF 应用按 `.NET 10 x64` 自包含制品安装到当前用户目录，默认不要求管理员权限，不做全机共享安装。
2. 桌面端和 UXP `.ccx` 是独立制品、独立版本和独立 hash，但由同一安装入口编排：环境检查 -> 安装桌面包 -> 引导/调用 `.ccx` -> 检查 plugin ID/manifest/protocol 兼容 -> 首次 bridge 能力探针 -> 标记可生产。
3. 生产包不得使用 Developer Tool 探针 ID、`network.domains: all` 或未签名/自签名客户包。正式 plugin ID、最小权限和 Adobe 支持的 `.ccx` 私有安装路径必须在 `INSTALL-01` 冻结。
4. 升级分别维护应用版本、UXP manifest 版本、RenderPlan 协议版本和 DB schema 版本；不兼容时暂停任务，不降级执行。应用替换失败可回滚旧程序，模板库、任务库、凭据引用和正式输出保留。
5. 普通卸载只移除应用和插件，默认保留模板、任务记录、应用数据和正式输出；只有用户明确选择并二次确认，才删除应用自有数据库、缓存、临时文件和内部模板副本。源 PSD、源图、尺码图、人工结果和正式输出永不由卸载器删除。
6. 每次封闭交付提供签名信息、SHA-256、SBOM/CVE 摘要、支持矩阵、已知限制、安装/卸载说明、上一稳定版本回滚包和脱敏安装日志；不提供静默自动更新。

## 候选与取舍

| 方案 | 优点 | 风险 | 结论 |
| --- | --- | --- | --- |
| 当前用户签名 bootstrapper + 配套 `.ccx` | 适合小范围协助安装，权限和数据边界清晰 | `.ccx` 自动化和 UAC 行为需实机验证 | **采用** |
| 应用商店/MSIX | 安装信任和更新体系完整 | UXP、外部目录、Photoshop 和内测节奏复杂 | 不作为 V1 |
| 未签名 ZIP/脚本安装 | 制作快 | SmartScreen、杀毒、来源信任和篡改风险不可接受 | 禁止 |

## 影响

- 签名不是“以后再补”的客户门槛：任何未签名或自签名包只能在项目方受控设备测试，不得进入外部客户电脑。
- `.ccx` 安装失败不得把桌面端标为可生产；首次逐机探针是最终准入判据。
- 该 ADR 不增加账号、支付、云同步、后台授权或平台上传。

## 退出条件

### 2026-09-25 本机内部补丁升级核验

在受控设备以原local开发ID做0.1.0同版本CCX更新时，Adobe Package内容核验通过，现有签名有效UPIA报告安装成功/exit0，但External目录main.js仍旧hash。安装成功文字和exit码不足以关闭升级门，必须逐资产核验安装字节并从新宿主进程完成认证。本次失败证据保留，不直接改External文件或删除受保护存储。

下一内部构建提升为0.1.1：manifest、JS challenge/handshake申报、桌面精确准入常量共同更新；JS从manifest读取版本，桌面仍只接受明确配套补丁版本，0.1.0/未知补丁不得在活动认证中伪装0.1.1。ps-bridge/v1、ps-adapter/v1、plugin ID/权限和历史执行数据不变；旧密码学向量保持只读测试。程序与CCX配套更新，重启后验证原受保护配对可复用，不复制或暴露秘密。此项仍是本机内部测试，非正式签名客户发布。

14:16实证增量：0.1.1已完成Adobe Package/UPIA安装和七公开资产逐字节核验；新PS/App隐藏面板两次3心跳、原配对直接复用及实际取消/监听释放通过。包hash及证据见[D6c新款报告](../验证/V1-D6c新款套版与尺码阻断-20260925.md)。只关闭本机升级/认证子门，不关闭open候选真实渲染、客户ID/签名/干净机安装或完整INSTALL。

若 Adobe 正式机制不允许预期的 `.ccx` 自动编排，安装向导必须保留明确人工确认步骤；若签名、回滚或卸载保留无法验证，暂停客户发布并形成新 ADR。
