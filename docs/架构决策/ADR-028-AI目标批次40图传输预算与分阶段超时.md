# ADR-028：AI 目标批次 40 图传输预算与分阶段超时

## 状态

已批准并实现（2026-09-12，上传阶段参数由 ADR-029 于 2026-09-13 更新）。本 ADR 是
当前新请求的传输参数补充；不改写 ADR-015、ADR-026、ADR-027 中已经发生的历史请求、
账单和失败证据。

## 背景

旧实现把普通目标批次和参考学习都按 24 张、180 秒总截止处理。24 张并不是
供应商允许的普通目标批次上限，而是旧实现层的数量门；同时，旧 V2 副本在真实
网络上可能在 180 秒内仍未完成上传。另一方面，参考学习需要保持更小且独立的
输入边界，避免把学习样本和日常目标素材混用。

本次调整只针对传输与等待边界，不改变动态规则、结果校验、缓存/ledger、授权、
费用预算、RenderPlan 或源文件只读约束。

## 决策

### 1. 普通目标批次与参考学习分开设限

| 请求路径 | 当前单次图片数上限 | 说明 |
| --- | ---: | --- |
| 普通目标批次 `ai-analysis/v1` | **40** | 目标款整组联合分析；41 张在 provider 前明确拒绝 |
| 参考学习 `reference-learning-ai/v2` | **24** | 参考 PSD 有效框反向引用的学习素材；25 张在 provider 前明确拒绝 |

40/24 是应用传输边界，不是 PRD 的整批性能目标，也不代表供应商账单或准确率
已经验收。队列容量、HTTP 并发、每款逻辑请求数、重试和单批预算仍沿用既有
安全上限。

### 2. 当前分析副本使用 V4

新请求默认使用
`wic-bounded/max1280/jpeg-q82/png-opaque-jpeg/v4`：

- 最长边 1280；
- JPEG quality 82；
- 不透明 PNG 确定性转为 JPEG；
- 含真实透明像素的 PNG 保留 PNG；
- 只生成应用自有分析副本，源 PSD、源照片和正式输出不改写；
- V4 使用独立 profile/fingerprint/cache 身份，禁止复用 V1/V2/V3 的旧字节或旧
  结果冒充 V4。

### 3. 最终请求体预算

适配器在 HTTP 发送前构造最终 UTF-8 JSON，并以实际字节数执行 **16 MiB
（16 × 1024 × 1024）** 预算预检。该数值是应用本地的内存/传输安全门，不是
火山 API 声明的硬限制；超限必须在 provider 前持久化明确错误并保持 HTTP=0。

### 4. 总截止与分阶段截止

当前默认值如下：

| 阶段 | 默认上限 | 起算与行为 |
| --- | ---: | --- |
| 总请求墙钟 | **300 秒** | 从 HTTP 传输 scope 开始，覆盖上传、响应头和响应体；不依赖 `HttpClient` 默认 timeout |
| 上传绝对上限 | **240 秒** | 请求体写入传输通道的绝对时间；原 180 秒值由 ADR-029 更新 |
| 上传无进度上限 | **90 秒** | 连续没有上传进度回调即截止；原 45 秒值由 ADR-029 更新 |
| 响应头等待 | **120 秒** | 上传完成后等待响应头 |
| 响应体读取 | **60 秒** | 收到响应头后读取完整响应体 |

各阶段还受剩余总墙钟约束；因此 300 秒不是把每个阶段简单相加后再额外赠送
一个窗口。取消由调用方单独分类为 `Cancelled`。

### 5. 超时、网络错误与重试

- 请求体尚未完整上传时的超时/网络中断，映射为 `RetryableError`（提交未送达），
  由既有 scheduler 安全上限决定是否重试；UI 明确显示“AI 请求未送达/火山未受理”。
- 请求体已完整上传但响应头或响应体失败时，映射为 `AiResultUnknown`；禁止自动
  重发、删除未知请求记录或猜测费用。
- 适配器对迟到的底层 HTTP task 继续后台观察后释放资源，前台不再被不响应取消的
  handler 无限阻塞。

## 不变的边界

- 现有 `MaxQueueCapacity=32`、`MaxConcurrentRequests=8`、每款最多 3 个逻辑请求、
  每个逻辑请求最多 2 次实际尝试和单批预算/费用门不因本 ADR 放宽。
- `AiResultUnknown` 不自动重试；缓存、request ledger、usage 和 checkpoint 仍按
  原子/单调规则保存。
- 不上传原始 PSD、源照片、绝对路径或凭据；不修改用户源文件，不把旧失败批次
  重新当作 V4 成功批次。
- 参考学习的动态语义、目标款的唯一 `ai-analysis/v1` 生产匹配链和 RenderPlan
  边界不变；本 ADR 不把参考照片写入未来目标款请求。

## 与既有 ADR 的关系

- ADR-015 的供应商无关端口、凭据、缓存、费用和未知结果原则继续有效；其 2026-08-30
  的 24 张/180 秒/V1 参数是当时的历史配置，**新请求的数值以本 ADR 为准**。
- ADR-026 的 180 秒历史上传失败分类、迟到 task 清理和未知结果安全门继续有效；本 ADR
  将新请求的总墙钟改为 300 秒并显式化阶段上限，上传绝对/无进度的当前值由 ADR-029
  更新为 240/90。
- ADR-027 的 V3 请求体诊断和上传阶段证据继续作为历史证据；新请求采用 V4，旧 V3
  请求、缓存和账单不回写、不重放。
