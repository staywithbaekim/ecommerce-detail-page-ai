# ADR-034：尺码校准模板包 v2 与索引兼容

日期：2026-09-20。状态：RENDER-01 实现候选，自动化和受控样本验证后记录证据；不代表阶段验收。

RENDER-01 的显式尺码插入规则需要随模板修订迁移。ADR-018 冻结的 template-package/v1 没有尺码校准字段，其 inspection 路径是 1-based；现有 PSD worker 使用 0-based 路径。不能通过给 v1 增加未知字段或放宽索引来改变既有合同。

新增 template-package/v2，沿用现有导出/导入服务、ZIP 安全限制和新身份导入流程。新导出使用 v2；旧 v1 仍按原 Schema 和语义读取，未知版本继续拒绝。v2 的 inspection 与 worker 一致，路径从 0 开始；FrameBinding 和尺码校准根索引仍从 1 开始，语义校验显式转换比较。v1 导入在边界处将 inspection 和 clippingBase 路径减一，绑定不变；不重写旧文件、旧修订或旧摘要。

v2 页面可包含 size-table-template/v1 校准：模板 hash、明确锚点、隐藏旧层、安全区域和确定性栅格样式。导入必须验证校准与原模板检查一致；普通页不可携带尺码校准。v1 不接受该字段。旧客户端对 v2 稳定拒绝，不丢弃规则后继续导入。

导出投影把合法裸结构摘要规范为 sha256: 摘要，并排除只用于渲染输出核验的 ContentEvidence；保留像素贡献和已有智能对象证据。原数据库 inspection 不变，源 PSD 只读；未知字段、错误模板 hash 和路径仍失败。模板包导入不视为 Photoshop 准确预览成功。

验收覆盖 v1 读取与索引转换、v2 尺码校准与普通页往返、严格 Schema/未知字段/非法索引/不匹配绑定/源 hash，以及真实模板副本的包导出与新身份导入。真实渲染继续按 ADR-014，不由模板包绕过执行门。

## 2026-09-22：v2 候选冻结前补齐替换栈

完整模板接入发现普通页包投影遗漏已有 `FrameBinding.SupersededLayers`，使导入与另存为丢失隐藏旧商品层的动作。此为未冻结 v2 实现候选的缺陷修复：绑定新增可选 `supersededLayers`，携带一基路径、固定 smartObject 类型、expectedVisible=true、expectedClipping 和可空正整数层 ID。无旧层的新包省略字段；旧 v2 缺字段按空列表读取。有旧层时完整导出并恢复，不猜旧包中已丢失的规则。

冻结 v1 Schema/语义保持不变，任何新字段（包括显式 null）在 v1 中仍拒绝。旧 v2 客户端的严格未知字段校验会拒绝含此字段的新包，不会静默丢弃；该拒绝属于包无效，不宣称是未知版本错误。v2 尚未对外交付或冻结，因此不另立 v3；若发布冻结后再改变合同，应新增版本。

语义检查按页面验证 inspection path/层 ID 唯一；所有主目标与旧层不得重复认领同一实际图层。旧层路径必须精确匹配检查结果，指定 ID 时必须一致，且为可见、有效可见的嵌入智能对象，clipping 匹配。几何重叠不作为身份冲突，不新增与现有 RenderPlan 不同的替换栈几何规则。校验不替代正式渲染前的 PSD/证据复核；包中仍不携带商品照片、AI结果或源绝对路径。
