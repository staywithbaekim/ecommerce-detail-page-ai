# ADR-018：模板包 v1 与本地新身份导入

## 状态

已批准并由 TPL-S6 实现。

## 日期

2026-08-28

## 背景

TPL-01 要求模板组可在不同本机数据根之间迁移，同时保持当前有效修订的 PSD 内部副本、页面配置、图片框结构证据和校准规则。模板包不得携带 API Key、凭据、任务历史、客户源照片、人工结果、绝对本机路径或废弃修订，也不能在 ID 冲突时静默覆盖现有本地模板。

## 决策

1. 模板包协议固定为 `template-package/v1`，ZIP 只作为容器；根目录包含一个 `manifest.json`，其结构由 `docs/技术方案/schemas/template-package-v1.schema.json` 冻结。
2. V1 只导出模板组当前已提交修订。每个内部 PSD 副本是白名单条目，记录逻辑资源 ID、相对包路径、长度和 SHA-256；页面记录品类中立的内容类型、生成方式、结构 inspection 和 `FrameBinding`。
3. 导入先在只读 ZIP 中完成协议主版本、条目唯一性、路径、长度、SHA-256、页面引用闭合和结构证据检查；未知主版本、绝对路径、盘符、反斜杠、`..`、重复条目、缺失内容或 hash 不符一律拒绝。
4. 导入和“另存为”始终创建新的本地 `group_id`、`revision_id`、`resource_id`、`page_id` 和 `frame_id`，不自动合并或覆盖同名/同 ID 模板。显示名称可由用户确认；V1 不提供自动合并。
5. 通过校验的 PSD 写入应用自有 staging，随后由 SQLite 单 writer 保存资源、页面和绑定，并复用修订 `ready.marker -> SQLite current_revision_id -> committed.marker` 提交流程。数据库已提交但缺少 committed marker 时，重复命令依据当前指针和 manifest digest 补写 marker，不猜成功。
6. 模板包不保存校准代表款素材本身。`selection_requirement` 中的校准 asset ID 只作为规则/示范引用；后续真实批次仍由 AI-01 或人工选择生成新的高分辨率资源映射。
7. 导出与导入不触发 Photoshop，也不写入 `TemplatePreviewStatus.Succeeded`。跨机导入的页面保持 `NotPreviewed`；首次准确渲染继续受 Photoshop/UXP 兼容性门控制。

## 安全与兼容

- ZIP 条目只接受 `/` 分隔的相对路径，不接受符号链接或解压逃逸目标；当前实现以有界条目数和逐条流/长度/hash 校验读取，不直接解压到用户路径。
- 包中不包含源绝对路径、任务/批次快照、日志、缓存、Key、凭据、客户源照片或人工结果。敏感字段或路径在导出前和导入时均拒绝。
- `template-package/v1` 的未知主版本稳定返回不支持/无效包错误；未来字段或语义变化必须新增协议版本和迁移 ADR，不能修改已发布 v1 含义。

## 取舍

| 方案 | 结论 |
| --- | --- |
| 当前修订 + 新本地身份 | 采用；冲突行为确定，不覆盖现有模板，包体范围可审计 |
| 导出完整修订历史 | 不采用；扩大包体、隐私和兼容面，TPL-01 不要求历史浏览 |
| 同 ID 自动替换或合并 | 不采用；可能破坏活动引用和既有批次快照 |
| 包中携带代表款源照片 | 禁止；违反源素材和隐私边界 |

## 影响

- 模板包是跨电脑长期合同，Schema、正反例和主版本拒绝测试进入 Contracts。
- 另存为复用同一导出/导入合同，并仅在应用自有 `template-package-staging` 中使用临时包。
- 完整模板库跨卷迁移仍属于 DATA-01；本 ADR 只覆盖单个模板组包的安全导入导出。
