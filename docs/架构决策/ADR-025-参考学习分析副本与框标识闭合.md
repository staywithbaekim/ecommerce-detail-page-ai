# ADR-025：参考学习分析副本版本与供应商框标识闭合

## 状态

已批准并实现（2026-09-11）。

## 背景

参考学习的整组语义请求复用了 AI-01 的 WIC 分析副本和 16 MiB 最终 JSON 请求体安全门。真实 11 张参考照片复验发现，继续使用旧 V1 profile 会让 PNG 在 Base64/JSON 后超过安全门；切换到 V2 后，供应商在多框结果中复写长随机 `frame_id`，如果直接接受会把语义写到错误图片框。

## 决策

1. `ReferenceLearningAiService` 的生产参考学习请求固定使用 `wic-bounded/max1600/jpeg-q82/png-opaque-jpeg/v2`。该版本进入请求、cache fingerprint 和兼容性检查；旧 V1 cache 保留用于审计但不可在当前路径复用。
2. `reference-learning-ai-v2.schema.json` 同时允许历史 V1 和生产 V2，以保持旧缓存/会话可读；应用新建请求不得回退到 V1。
3. 供应商提示词为本次请求的每个图片框分配短、确定性的 `f_01`…`f_N` alias。适配器在本地将 alias 按请求内位置映射回真实 `frame_id`，然后继续执行重复、缺失、越界和集合闭合校验。供应商返回未知 ID、错数量或重复 ID 时仍 fail closed。
4. Alias 只用于供应商传输，不进入领域持久化、模板包、RenderPlan 或用户界面；真实稳定 ID 仍是唯一内部事实源。

## 结果与边界

- 真实 6 页/11 框参考语义请求已成功通过严格 v2 结果校验；未放宽 180 秒 `AiResultUnknown`、请求体、授权、费用或源文件只读边界。
- 目标款仍只通过既有 `ai-analysis/v1` 生产链路分析，不新增第二套目标匹配请求、cache 或 usage 事实。
- 供应商仍只接收有界分析副本；不发送本地路径、原始高清文件、PSD 或 API 凭据。
