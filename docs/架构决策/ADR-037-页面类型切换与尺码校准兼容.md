# ADR-037：页面类型切换与尺码校准兼容

日期：2026-10-17。范围：TPL-02 尺码模板闭环；尺码 PSD 暂不接参考款学习。

页面自动识别结果与用户当前选择分别保存。新导入由 Application 根据 PSD 检查结果识别，用户切换不改写识别记录。SQLite 追加 v29，旧页面按原 content_type 初始化记录；不改变 v1–v28 校验和，不重算历史修订、批次或输出摘要。

普通图片位绑定和尺码插入校准分别保留。切换只改变当前页面类型，普通页不得执行留存的尺码校准，尺码页不得执行普通图片位绑定。显式配方与新类型冲突时继续提示修正规则，不静默改写生成次数、颜色或配方。无目标款数据可保存模板；正式生产仍需通过尺码来源、审核、栅格和插入目标校验。

模板包 v1–v5 的 Schema 和拒绝语义保持冻结，尤其普通页不得携带尺码校准。新增 template-package/v6，携带页面识别记录，允许普通页留存经结构匹配验证的尺码校准。新导出使用 v6；旧版本仍可导入，缺少识别记录时按原页面类型初始化。v6 严格拒绝未知类型/字段、过期校准和非法索引。识别记录仅为建模说明，不加入既有业务摘要；实际类型、绑定和校准仍由原摘要覆盖。

工作台在尺码卡片提供现有区域/样式校准入口及保存状态，不新增正常流程配置页。用户确认隐藏旧表层、安全区域与样式，生成继续复用确定性尺码 PNG 和 renderer-neutral RenderPlan；不把模板旧数值当作目标款数据，不修改 Photoshop/UXP、manifest、checkpoint 或 bridge 合同。
