## 迁移机制

- 迁移版本：1-26，按连续版本执行。
- schema_migrations(version, applied_at, checksum) 保存已执行版本和校验值。
- 已执行迁移的 checksum 不匹配会阻断启动。
- 缺少前一版本会阻断，避免跳跃迁移。
- 数据库连接统一启用 WAL、foreign_keys、busy_timeout、synchronous=FULL。
- 第 13 版对历史数据库按列存在性执行兼容升级。

## 已确认的关系和保护

- 任务事件通过 task_id 关联 tasks，并以 (task_id, sequence_no) 唯一约束保证事件顺序。
- 模板页、模板绑定、批次快照、输入样式和输入资产通过批次/模板 revision 关联。
- 实例生产事实以 (batch_id, style_id) 为主键，生产证据 JSON 同时保存 payload_digest。
- 实例投影快照、投影命令和投影成员按批次/样式形成冻结边界，并通过 command digest、projection digest、snapshot version 防止重复或篡改。
- 手动选择以 (batch_id, style_id) 为主键，revision 和 payload_digest 用于并发修改检测。
- 连接级 foreign_keys=ON，写操作经统一写队列和事务执行。
