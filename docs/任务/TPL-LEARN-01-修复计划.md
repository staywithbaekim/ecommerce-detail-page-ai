## 一、验收测试发现的问题

### P0 阻塞级缺陷

#### BUG-001: AI生成的选图规则无法使用
**问题描述：**
- 学习阶段生成的规则过于模糊："商品展示图（与参考款保持同一视角，请确认）"
- 10个图片框中9个规则完全相同
- 批次分析时AI无法区分不同框的需求
- 导致匹配准确率极低，核心功能不可用

**用户预期：**
生成明确的语义标签，如：
- "真人模特正面站姿图"
- "假模特平铺正面图"
- "领口特写图"
- "面料质地细节图"

**当前生成：**
- "商品展示图（与参考款保持同一视角，请确认）" × 9个框
- "领口图" × 1个框

**影响范围：** 核心功能完全不可用  

**根本原因（已确认）：**
AI提示词中的 `frame_context` 字段对所有图片框使用完全相同的硬编码值：
```csharp
// src/Desktop.Application/Templates/ReferenceLearningAiService.cs:175-181
"基于已匹配参考图的可见内容生成可消歧要求；结构与资格已经由本地证据确认。" // 所有框都是这个！
```

导致AI无法区分不同框的用途。所有框的 `layout_intent` 也都是 "subject_cover"。

**代码位置：**
- `src/Desktop.Application/Templates/ReferenceLearningAiService.cs:175-181`
- `src/Desktop.Application/Templates/ReferenceLearningService.cs:1006-1011`

**修复方案：**
1. 将图层名称（`Name`）传入 `frame_context`
2. 根据图片框特征生成不同的 `layout_intent`
3. 改进AI提示词，让AI根据图片内容生成具体描述

---

#### BUG-002: PSD重复检测阻塞正常操作
**问题描述：**
- 用户尝试重新学习已存在的PSD时，系统提示"检测到内容相同的PSD"
- 提供的三个选项（保留已有/保留本次/复用）都会报错
- 错误码：`TPL_DUPLICATE_SELECTION_INVALID`

**用户影响：**
- 无法重新学习模板
- 无法使用相同PSD创建新模板组

**复现步骤：**
1. 导入一组PSD完成学习
2. 尝试重新导入相同的PSD
3. 选择任意选项都会报错

**根本原因（已确认）：**
每次导入PSD都会基于SHA256查询重复，强制用户决策。即使用户只想重新学习，也必须处理重复决策对话框。

**代码位置：**
- `src/Desktop.Application/Templates/TemplatePageImportService.cs:72-100`

**修复方案：**
1. 为学习流程添加"自动重用草稿中的重复PSD"选项
2. 提供"跳过重复检查"模式
3. 记住用户的重复处理偏好

---

#### BUG-003: PSD检查worker无法处理中文路径
**问题描述：**
- Worker是Python程序，无法加载中文路径下的python310.dll
- 错误信息：`Failed to load Python DLL`

**用户影响：**
- 中文路径用户无法使用（如"全新实现"、"测试文件夹"）
- 必须将应用放在纯英文路径下

**临时解决方案：**
- 将应用移到英文路径（如 C:/Users/79122/Documents/test-20260911/）

**根本原因（已确认）：**
C#主进程已正确设置UTF-8编码，但问题在于Worker子进程（Python）内部可能使用了错误的编码读取包含中文的文件路径。

**代码位置：**
- `src/Desktop.Infrastructure/Psd/PsdInspectionWorkerClient.cs:96-112`

**修复方案：**
1. 检查Python worker脚本的编码设置
2. 在worker端添加UTF-8解码验证
3. 添加中文路径的集成测试
4. 考虑将路径转为短路径（8.3格式）作为临时方案
