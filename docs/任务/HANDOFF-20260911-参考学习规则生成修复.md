## 问题概述

**用户需求：**
用户提供PSD模板 + 源照片文件夹 → 系统学习生成选图规则 → 用户确认规则 → 批量生产时自动匹配照片到对应框

**当前缺陷：**
AI生成的选图规则过于通用，所有图片框都显示"商品展示图（与参考款保持同一视角，请确认）"，无法区分具体的视觉内容（如"领口特写图"、"面料细节图"等）。

**影响范围：**
- 用户无法理解每个框的具体用途
- 批量生产时AI无法精确匹配照片
- 整个"从人工结果学习"流程的核心价值受损

## 架构理解

### 完整的规则生成流程

```
[学习阶段]
1. 用户导入PSD + 参考照片
2. PSD检查提取图片框（图层ID、名称、位置、大小）
3. 本地推断生成LayoutIntent（detail_crop、hero_centered等）
4. 生成FrameContext（图层名+布局提示："图层名称：领口；小尺寸特写框；竖版构图"）
5. 调用火山方舟AI：
   - 输入：参考照片 + FrameContext + LayoutIntent
   - 输出：SelectionRequirement（"领口细节特写图（展示领口设计和做工）"）
6. AI生成的SelectionRequirement → 存储为candidate.SemanticLabel
7. 用户在"页面校准"界面看到规则并确认

[批量生产阶段]
1. 用户导入新款照片
2. AI分析每张照片的视觉内容
3. 匹配规则：photo_123.jpg 的内容是"领口特写" → 放入需要"领口特写图"的框
4. 自动套版完成
```
