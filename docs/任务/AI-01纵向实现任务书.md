### 已冻结的架构边界

- **ADR-010**：AI 请求和结果必须绑定创建批次时的 `BatchTemplateSnapshot`；模板组后续修订不得改变分析中的页面、图片框需求或规则摘要。
- **ADR-011**：WPF + .NET 10 只负责桌面交互和状态投影；AI 规则、Prompt、供应商 DTO 和 Photoshop 动作不进入 Presentation，首发环境仍是 Windows 11 x64。
- **ADR-012**：分析请求 ledger、规范化结果、缓存引用和用量事件必须通过 SQLite/WAL 单 writer、manifest/checkpoint 和原子提交持久化；崩溃恢复不得把未知请求猜成成功。
- **ADR-013**：AI 不直接调用 Photoshop bridge；bridge 只接受已校验 renderer-neutral RenderPlan，loopback、token、nonce、心跳和未知执行语义保持隔离。
- **ADR-014**：AI 结果只能作为领域输入构造 RenderPlan，不能把供应商响应、路径、凭据、命令或临时分析资源写入 RenderPlan。
- **ADR-015**：火山方舟只存在 Infrastructure adapter；Key 按请求从 Credential Manager 注入；缓存键、有限重试、`AiResultUnknown`、用量和费用停止门按该 ADR 执行。
- **ADR-018**：模板包不携带 API Key、任务历史、代表款源素材或 AI 缓存；AI 只能消费当前批次正式资产，不得从模板包恢复业务素材。

分析副本边界：`BatchDraft.Assets` 的 INPUT-01 源登记只读作为副本生产输入；`IAiAnalysisCopyPreparer` 在应用自有目录生成带独立 digest、长度、MIME、压缩配置版本和 lease 的副本，`IAiAnalysisCopySource` 在联网前复核元数据与实际字节。副本生命周期由应用 lease/阶段协调，不由 provider adapter 删除；源路径、源字节和 Key 不进入 AI request、SQLite、manifest 或日志。

## 2. 目标与完成定义

在现有 TPL-01 模板快照、图片框选图需求和 renderer-neutral 边界之上，建立可恢复、可解释、可人工修正的正式 AI 纵向链路：

`批次素材清单 -> 受控压缩副本与授权 -> 款内联合分析 -> 候选/变体结果 -> 最终候选主体分析与尺码来源识别 -> 本地结构校验 -> 人工锁定/切换/纠错 -> 版本化分析结果、用量和缓存 -> B-03 生成计划输入`。

完成不是“有一个接口”或“测试数量足够”，而是同时具备：

- 真实火山方舟请求在独立测试项目中按批准授权执行，并有脱敏请求/响应合同、费用、延迟和停止证据；
- Domain/Application 只依赖供应商无关端口和版本化合同，非法或不完整响应在进入领域层前被拒绝；
- 有界队列、按款分层混合分析、缓存、重试和未知结果处理可重启恢复；
- 人工选图可锁定、切换和逐图重新适配，AI 不覆盖锁定选择；不支持的自然语言指令被拒绝；
- 结果能驱动 B-02/B-03 的渐进状态和页面级绿/黄/红，不把红页或缺失值猜成可生成；
- 真实金标回归覆盖服装多变体、动态尺码图、低清/冲突/缺失素材，并在取得一组已校准非服装样本后完成品类中立回归；
- 重启、断网、429、超时、5xx、响应未知、撤回授权、预算/费用停止和磁盘/持久化失败均有可复现分因和恢复动作；
- 代表页面已在实际 WPF 应用中由产品负责人走查，文案为中文、可行动且不暴露模型 ID、结构签名或凭据。

## 3. 硬约束与非目标

### 3.1 必须遵守

- V1 固定火山引擎“火山方舟”服务；候选模型 ID 为 `doubao-seed-2.1-pro-260628`，仅在真实金标、P95、费用和数据处理证据共同满足后才能从 `proposed` 变为生产配置。当前普通分析输出上限修正为 `4096`，以 `doubao-seed-2.1-pro-260628-output4096-v2` 作为独立 model-config 版本参与 request fingerprint；普通设置页不提供供应商、模型、Base URL 或高级参数选择。
- API Key 只从 Windows Credential Manager 按请求作用域读取。测试 Key 仅存开发机专用凭据槽，不进入源码、配置样例、SQLite、manifest、模板包、日志、诊断包、安装包、API 响应原文或客户电脑；客户 Key 升级时不得静默上传。
- Domain/Application 只依赖 `IAiAnalyzer`/`IAiServicePort`、`IAiCredentialSource`、`IAiUsageRecorder` 等供应商无关端口和版本化 `AnalysisRequest`、`AnalysisResult`、`UsageEvent`。火山方舟 SDK、端点、认证头、原始响应和供应商错误映射只存在 Infrastructure adapter。
- 上传只使用必要的压缩分析副本；不上传 PSD、高清源图、市场尺码图原件或本地路径。需要识别尺码结构时，只能上传应用从获准尺码图生成的必要压缩分析副本；源 PSD、源照片、人工结果和尺码图保持只读。
- 缓存键遵守 ADR-015：排序后的资产内容 hash、分析类型、模型/Prompt/响应 Schema/压缩配置版本和模板需求摘要；人工选择、状态和本地路径不得进入内容键。活动任务引用的缓存受保护。
- 先写 request ledger/fingerprint，再发请求；只有官方合同确认未接受或明确安全的网络短断、429、临时 5xx 才有限重试。供应商处理状态未知时标记 `AiResultUnknown`，禁止盲目重发。
- 响应在进入 Domain 前验证版本、引用闭合、rank 唯一性、置信度、几何有限值、尺码结构和未知字段策略；任何非法响应进入可解释待处理路径。
- 调度使用有界队列和按款分层混合分析：第一层联合理解单款素材与模板快照中的图片框需求；第二层只分析最终候选、确需主体级排版的已选素材及确有尺码内容的来源。不能整批巨型请求或为每张图/每个框重复拆请求。
- 领域模型、Prompt、SQLite、RenderPlan 不写死服装角色或“颜色”枚举；`selection_requirement`、变体维度和值来自校准事实和素材证据。非服装在取得真实样本前不得宣称通过。
- 只保留可解释证据摘要/标签，不记录模型隐藏推理过程；用户界面不显示结构签名、注册状态或供应商细节。

### 3.2 明确不做

- 不实现账号/租户、项目方统一网关、云同步、计费/支付、客户工作区、平台上传或通用批量重分析器。
- 不实现动态尺码表确定性栅格器、正式 Photoshop 批量渲染或 UXP 私有业务规则；AI-01 只输出可供 SIZE-01 和 RenderPlan 使用的结构化候选/来源事实。
- 不猜缺失素材或尺码值，不生成、重绘或改变商品，不贴入市场尺码原图。
- 不把 mock、离线 fixture、文档、合成响应或演示截图当作真实 AI 学习、语义选择、准确率、费用或延迟通过证据。

### 上传授权边界产品选择（2026-08-31，已批准并实现）

实现边界：S-01 设置页显示授权状态、范围说明、授权时间和重新读取/撤回/重新授权操作；`TryAcquireAsync` 是请求准入线性化点：撤回先提交则不预留预算、不进入 `Uploading`、不调用 provider、不标记未知结果并保持 `Queued`；准入先提交后发生的撤回不回滚已准入请求。准入事务只做本地状态读取，不跨 HTTP 持锁。授权版本为 `ai-upload-consent/v1`，作用域为 `ai-analysis-copy`。

## 5. 真实金标、费用与数据处理

### 金标最低集合

1. 现有已批准服装样本：真实 PSD、源照片、人工完成结果、页面图片框需求和多变体说明；仅用内部副本分析。

### 费用/延迟控制

- 任何联网、NuGet/Python 包安装或真实 API 调用先向用户请求审批；不得因自动审批、503 或网络失败绕过授权或建立替代下载链。
