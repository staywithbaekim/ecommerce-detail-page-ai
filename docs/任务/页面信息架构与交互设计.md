# 页面信息架构与交互设计

## 状态

已完成：PRD 1.3 已正式签署；信息架构、核心流程和低保真交互规格 v1.0 已由产品负责人确认。

## 目标

以已签署的 `产品需求文档-电商详情页智能生产系统-PRD-1.3.md` 为唯一需求输入，完成页面信息架构、核心流程、低保真交互和客户模板配置规格，为高保真设计、桌面端页面实现以及 AI-01、SIZE-01 正式纵向开发提供无歧义输入。

## 范围

- 桌面应用主导航、首页工作台和全局返回规则；
- 模板库、新建模板组、两种校准模式、页面排序与生成规则；
- 新建批次、AI 分析、绿/黄/红预检和页面级红色隔离；
- Photoshop 渲染进度、暂停恢复、失败状态和安全接管提示；
- 结果检查、Top-2/Top-3 换图、自然语言或手动调整、单页重生成；
- 动态尺码表编辑器、设置、存储清理和诊断入口；
- 首次使用、空状态、加载、无网络、Photoshop 未连接和恢复状态。

## 非目标

- 不重新解释或保留已经被 PRD 1.3 替代的更早版本口径；
- 不把 UXP 技术验证细节改写成客户功能承诺；
- 不在本任务中删除验证证据、用户样本或历史 Demo；
- 不把尚未完成的 AI-01、SIZE-01 或完整产品性能验收口头标记为已完成；
- 不在页面结构确认前冻结高保真视觉细节。

## 完成条件

1. 页面信息架构、核心流程和低保真线框图完成走查。
2. 每个核心页面的入口、主要信息、操作、离开条件和异常状态明确。
3. 模板配置、红页隔离、结果修复、暂停恢复和单页重生成在交互稿中可完整走通。
4. 页面设计不引入 PRD 1.3 之外的新范围，也不遗漏其中的 V1 必做能力。
5. 设置页能够走通固定 AI 服务与 Key、Photoshop 选择、存储迁移与安全清理、上传授权与诊断导出；删除任务或模板的确认文案明确不影响原始输入和正式输出。
6. `docs/验收矩阵.md` 能追踪页面实现、AI-01、SIZE-01、FLOW-01、DATA-01 和 SET-01 的后续证据。
7. `docs/当前项目状态.md` 记录设计产物、未决参数和下一项正式实现任务。

## 阶段产物

- `docs/设计/桌面端页面信息架构与交互规格-v1.0.md`：包含四个一级导航、页面/流程节点、端到端主流程、核心页面低保真、任务与页面状态、关键确认文案和 PRD 追踪。
- 交互式低保真预览：覆盖工作台、模板校准、新建批次、生成前检查、Photoshop 渲染、结果修复、任务和五个设置分区；作为本轮走查辅助，不替代仓库内设计规格。
- 预览已在 736px 和 360px 宽度检查：无横向溢出、按钮文字截断或脚本错误；模板、任务、设置和核心流程跳转可用。

## 已确认决定

1. 一级导航只保留工作台、模板、任务、设置。
2. 两种模板校准方式最终进入同一个三栏校准编辑器。
3. 新建批次在一个页面完成，提交后立即进入独立的页面级生成前检查，并渐进显示扫描、分析、人工配置和绿黄红状态。
4. 红页在款式内保留占位，正常页继续生成，结果页显示“完成但有问题”。
5. 结果检查使用缩略图总览，所有修复在单页编辑器完成。
6. 设置按五个分区组织，数据管理不单设一级页面。

补充确认：示例效果可选；动态尺码表是模板页面内容类型；结果单页修复不更新模板规则并支持按需 Photoshop PSD 返修；人工选图保留最终选中图的主体智能分析；批次内可新建或导入已校准模板；V1 全批计划收口前不提前启动部分渲染。

进入桌面端高保真视觉设计与可开发组件规格；随后按正式纵向方式实现 AI-01、SIZE-01。任何后续调整必须更新唯一活动 PRD 或当前设计基线，不得恢复 PRD 1.2、设计 v0.1 或本轮已经替代的旧口径。
