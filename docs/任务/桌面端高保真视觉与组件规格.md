## 目标

严格依据 `产品需求文档-电商详情页智能生产系统-PRD-1.5.md` 和 `docs/设计/桌面端页面信息架构与交互规格-v1.2.md`，在新的 Figma Design 文件中从零构建桌面端高保真原型。覆盖全部页面、弹窗、抽屉、浮层、全局组件、状态和关键交互，并形成开发可直接使用的一份当前设计规格。

## 约束

- 唯一产品输入是 PRD 1.5 和低保真交互规格 v1.2；历史原型、聊天内容和外部参考不作为开发读取入口。
- 页面结构、业务内容、导航、文案和状态必须从当前两份基线推导；信息不足时标记 `[需产品确认]`。
- 不修改用户 PSD、源照片或人工参考结果。
- 保持一个新 Figma 高保真源文件和一份当前有效的设计交付规格，不为单个页面拆分零散文档。

## 已确认视觉方向

- 产品载体仍是 Windows 桌面专业生产工具，但整体视觉感受采用产品负责人旧 Figma 所体现的 iOS 式设计语言：干净轻盈、留白明确、灰阶柔和、层级克制、细边框、适度圆角和精致状态反馈。
- “iOS 式”只定义视觉气质，不把产品改造成移动端或 macOS 应用；窗口适配、鼠标键盘操作、信息密度、路径选择和长任务管理仍按 Windows 桌面生产场景设计。
- 不使用 iPhone 页面结构、手机底部导航、macOS 红黄绿窗口按钮、大面积毛玻璃或不适合生产工具的高透明效果。
- 主要操作色：黑色；蓝色不作为主要按钮和主要命令颜色。
- 绿、黄、红只承担业务状态语义，并同时配合图标和文字，不能只依赖颜色。
- 主工作区、摘要卡、筛选行、列表行、底部栏和弹窗表单等结构性核心容器使用 Auto Layout，由父容器控制方向、间距、对齐和窗口伸缩；这不要求每个图层都使用 Auto Layout，自由拖拽校准画布、图片叠层、浮层锚点和装饰元素可以使用固定坐标。重复状态使用 Variants，视觉值使用设计变量。
- 黑色主操作的最终色值、悬停/按下/禁用层级，以及蓝色是否仅保留给焦点或链接，在视觉基线板走查时冻结，不提前凭空指定。

## 当前高保真设计规则

1. **人能看懂的状态名称**：用户界面优先显示“可生成 / 待检查 / 不可生成”等业务文字，并配合小状态灯或图标；不得直接显示“绿 / 黄 / 红”等内部分类名，内部仍保持 PRD 定义的绿黄红状态模型。
2. **生成前摘要**：在既有 B-03 和 Photoshop 安全接管流程内集中显示模板快照、已选款式、计划页面数、红页隔离数、输出格式、输出目录和预计 Photoshop 占用时间，不新增重复的生产页面。
3. **视觉门禁信息**：T-05、B-03 和结果检查中用明确原因表达白边、主体切断、旧商品残留、裁切目标冲突等问题，避免只显示笼统的“需要确认”。
4. **AI Key 完整状态**：设置页覆盖未配置、测试中、测试成功、测试失败、已配置、更换和移除确认，并在失败后保留用户尚未提交的输入；不显示供应商、模型或 Base URL 选择。
5. **路径和输出反馈**：目录选择展示完整目标路径、可写状态、输出目录结构预览和同名冲突结果；仍遵守每批次必须确认输出目录、不得静默覆盖的 PRD 要求。
6. **失败项就地行动**：失败行直接显示款式、页面、原因和“重试当前页 / 重试当前款 / 继续其他项”，与正常页面和生成前红页保持区分。
7. **校准画布三栏关系**：保留页面列表、稳定画布、素材/规则面板的清晰空间分工，但页面内容、规则字段和操作均使用当前 T-03 至 T-05 规格。

## V1 已确认补充边界

1. 所选目录直接包含支持格式图片且没有图片型一级子目录时，识别为单款批次；所选目录本身不含支持格式图片且一个或多个一级子目录包含支持格式图片时，识别为正常批次；两者并存时阻断并要求整理或重新选择，不猜测图片归属。
2. V1 不估算开始生成所需的磁盘空间，也不展示预计差额；输出不可写或实际写入时磁盘已满仍按任务级错误安全停止，清理不完整产物并保留已完成结果。
3. V1 不提供“全部未完成 / 当前筛选 / 已勾选”的通用批量重分析器。系统级错误恢复时只继续失败或未完成项；素材修正通过单款或单个图片框完成，避免重复 API 成本和误操作。
