## 三、解决方案设计

### 3.1 核心改进

**文件**: `ReferenceLearningService.cs`

**推断规则**:
```
面积 < 15% 或关键词匹配 → detail_crop (细节特写)

面积 > 50% 且居中 → hero_centered (主图)

```

#### 改进 2: 个性化框架上下文
**文件**: `ReferenceLearningAiService.cs`  
**方法**: 新增 `BuildFrameContext` (40 行)

**生成规则**:
```

基于已匹配参考图的可见内容生成明确选图要求
```

### 3.2 技术细节

**推断依据**:
- 图片框面积占画布比例 (area_ratio = frame_area / canvas_area)
- 图片框中心点相对位置 (relative_center_x/y)
- 图片框宽高比 (aspect_ratio = width / height)
- 图层名称和文件名关键词匹配

**关键词库**:
- 细节类: detail, 细节, 局部, 特写, collar, 领, sleeve, 袖, fabric, 面料
- 中英文混合支持，大小写不敏感
