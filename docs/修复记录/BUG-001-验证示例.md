## 布局意图推断规则速查表

| 条件 | layout_intent | 典型用途 |
|------|---------------|----------|
| 面积 < 15% 或包含细节关键词 | `detail_crop` | 领口、袖口、面料、标签特写 |
| 面积 > 60% | `full_product` | 完整商品平铺展示 |
| 面积 > 50% 且居中 | `hero_centered` | 主图、封面图 |
| 面积 15-50% 且左上 | `grid_top_left` | 网格布局第1格 |
| 面积 15-50% 且右上 | `grid_top_right` | 网格布局第2格 |
| 面积 15-50% 且左下 | `grid_bottom_left` | 网格布局第3格 |
| 面积 15-50% 且右下 | `grid_bottom_right` | 网格布局第4格 |
| 其他 | `subject_cover` | 通用商品展示 |

## 关键词检测列表

### 细节类（触发 detail_crop）
- 中文：细节、局部、特写、领、袖、collar、sleeve、fabric、面料
- 英文：detail, close, crop, collar, sleeve, fabric, texture

### 位置判断（画布分区）
- 左侧：centerX < 50%
- 右侧：centerX >= 50%
- 上方：centerY < 50%
- 下方：centerY >= 50%

### 构图判断（宽高比）
- 竖版：aspectRatio < 0.8
- 方形：0.8 <= aspectRatio <= 1.25
- 横版：aspectRatio > 1.25

## 已知限制

1. **图层名称为空或无意义**：如果设计师使用默认名称（"图层1"），则只能依靠位置和尺寸推断
2. **复杂嵌套结构**：多层剪切蒙版可能导致位置计算偏差
3. **非标准布局**：不规则排列的框可能被误判为网格布局
4. **AI 仍需训练**：即使提供了更好的上下文，AI 模型本身的理解能力决定最终质量
