### 2026-09-12 当前 AI 目标批次传输策略（ADR-028）

产品负责人已批准并已在当前代码中实现新的请求用途分界：普通目标批次 `ai-analysis/v1`
单次最多 **40 张**；参考学习 `reference-learning-ai/v2` 单次最多 **24 张**。41 张目标素材
和 25 张参考素材均在 provider 前明确拒绝。这里的 40/24 是应用传输边界，不是 PRD 的整批
性能目标，也不把供应商准确率或账单事实写成已验收。

新请求默认采用 `wic-bounded/max1280/jpeg-q82/png-opaque-jpeg/v4`：最长边 1280、JPEG q82，
不透明 PNG 转 JPEG，真实透明 PNG 保留 PNG；V4 使用独立的 compression profile、fingerprint
和 cache 身份，V1/V2/V3 旧副本和旧结果不冒充 V4。源 PSD、源照片和正式输出保持只读。

adapter 在 HTTP 前构造最终 UTF-8 JSON，并按实际字节数执行 **16 MiB（16×1024×1024）**
本地预检；这是应用安全预算，不是火山 API 硬限制。当前单次 HTTP scope 的总墙钟为 **300 秒**，
阶段上限为：上传绝对 240 秒、上传无进度 90 秒、上传完成后响应头 120 秒、收到响应头后响应体
60 秒；各阶段同时受剩余总墙钟约束，`HttpClient` 不设置更早的默认 timeout。
