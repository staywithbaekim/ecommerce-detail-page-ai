# 验收矩阵

本文件把已签署 PRD 的关键要求映射到可重复验证。状态只能依据可定位的报告、测试或产物更新，不能依据口头判断改为通过。

## 状态定义

- `待验证`：已有需求，尚无证据。
- `进行中`：验证环境或实现已经开始，但尚未达到完成条件。
- `通过`：有可重复步骤和产物证明满足要求。
- `失败`：已有证据证明当前方案不满足要求。
- `阻塞`：缺少环境、输入或外部条件，暂时无法继续。

## 更新规则

- 每个“通过”或“失败”状态必须链接到仓库内报告、测试输出摘要或可复现产物。
- 环境信息至少包含 Windows 版本、CPU、内存、磁盘类型、Photoshop 精确版本、插件版本和样本标识。
- 性能数据必须区分 AI 阶段、Photoshop 冷启动、Photoshop 热运行和文件保存时间。
- 视觉结论使用人工参考结果和双方认可的金标，不使用 JPG 二进制相同作为标准。
